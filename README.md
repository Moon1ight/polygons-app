# Polygon Editor

![Иллюстрация к проекту](https://github.com/Moon1ight/polygons-app/blob/main/public/polygons-app.jpg)

Одностраничное веб-приложение для создания и редактирования полигонов на Canvas.

---

## 🚀 Демо функционала

* Генерация случайных полигонов (3–7 вершин)
* Перетаскивание (drag‑and‑drop)
* Выбор и удаление
* Undo / Redo (Ctrl+Z / Ctrl+Y)
* Запрет пересечения полигонов
* Ограничение движения внутри canvas
* Информационная панель
* Анимация появления
* Экспорт / импорт сцены (JSON)
* Изменение цвета выбранного полигона
---

## 🛠️ Технологии

* Vanilla JavaScript (без фреймворков)
* Web Components (Custom Elements + Shadow DOM)
* Canvas API
* Webpack

---

## 🎮 Управление

### 🖱️ Мышь

* Клик по полигону — выбрать
* Клик по пустому месту — снять выделение
* Зажать и двигать — перемещение

### ⌨️ Клавиатура

* Ctrl + Z — Undo
* Ctrl + Y / Ctrl + Shift + Z — Redo
* Delete — удалить выбранный полигон

---

## 🧠 Архитектура

Приложение построено на Web Components:

* `<app-root>` — управление состоянием приложения
* `<canvas-area>` — отрисовка и взаимодействие
* `<toolbar-panel>` — UI-кнопки
* `<info-panel>` — отображение состояния
* `<app-toast>` — уведомления

Состояние хранится централизованно в `app-root`.

---

## 🔁 Undo / Redo

Реализовано через стек состояний:

* каждое действие сохраняет snapshot
* drag считается одним действием (фиксируется на mouseup)
* поддерживаются:

  * создание
  * удаление
  * перемещение
